## Цель
Научиться выделять повторяющиеся вычисления в функцию, передавать в неё массив (вектор) и явно сообщать об отсутствии результата.

## Описание
Даны два произвольных массива R и L размером k и n соответственно. Программа находит среднее арифметическое положительных элементов массива R и среднее арифметическое положительных элементов массива L. Ноль положительным не считается.

Расчёт вынесен в одну функцию `positiveMean`, она вызывается дважды: для R и для L. Ввод и вывод находятся только в `main`. Если положительных элементов нет, функция возвращает `false`, и программа сообщает об этом.

## Входные данные
1. Размер массива R (целое число от 1 до 100), затем его элементы.
2. Размер массива L (целое число от 1 до 100), затем его элементы.

Модуль каждого элемента не больше 1000. При неверных данных программа выводит `INVALID`.

Пример ввода:

```
5
1 2 3 -4 6.7
5
2 3.5 5.5 -1.2 4.2
```

## Выходные данные
Для каждого массива выводится среднее арифметическое его положительных элементов либо сообщение, что положительных элементов нет.

Пример вывода для входных данных выше:

```
Mean of positive elements of R: 3.175
Mean of positive elements of L: 3.8
```

## Как запустить
Открыть проект в Visual Studio и запустить без отладки: Ctrl+F5.
